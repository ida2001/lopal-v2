Моторные масла · Линейка Lopal 1 (龙蟠1号)

SAE 0W-20 API SP ILSAC GF-7A

Полностью синтетическое моторное масло линейки Lopal 1 по американской формуле Pro (净威美系Pro): классы API SP и ILSAC GF-7A, маловязкая SAE 0W-20, технология Vis-Power. Ориентир — автомобили американских и азиатских марок, включая гибридные силовые установки.

Преимущества

API SP

Актуальный класс API для современных бензиновых двигателей.

ILSAC GF-7A

Новейший класс ILSAC: экономия топлива и защита систем снижения выбросов.

SAE 0W-20

Лёгкий холодный пуск и снижение расхода топлива.

Vis-Power

Фирменная технология Lopal для стабильности плёнки и защиты от износа.
