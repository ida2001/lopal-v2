Мотор майлары · Линейка Lopal 1 (龙蟠1号)

SAE 0W-20 API SQ ILSAC GF-7A ACEA C6/C5

Современное полностью синтетическое моторное масло линейки Lopal 1 (龙蟠1号) по формуле «для всей серии». Классы API SQ и ILSAC GF-7A — новейшие стандарты для бензиновых двигателей, включая турбомоторы и гибриды. Технология Vis-Power (супермолекулярная полимерная технология, 超分子聚合技术) стабилизирует масляную плёнку и защищает детали от износа. Формула рассчитана на требования экологического стандарта Китай VI-B и маловязкие масла 0W-20.

Артықшылықтары

API SQ · ILSAC GF-7A

Новейшие классы API и ILSAC: защита от преждевременного воспламенения (LSPI), износа цепи ГРМ и поршневых колец.

SAE 0W-20

Маловязкая формула: уверенный холодный пуск, быстрый выход на защиту и снижение расхода топлива.

Технология Vis-Power

Супермолекулярная полимерная технология: стабильная масляная плёнка под нагрузкой и чистота деталей.

ACEA C6 / C5

Малозольные классы: совместимость с современными системами нейтрализации отработавших газов.
