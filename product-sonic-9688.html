Моторные масла · Линейка Lopal 1 (龙蟠1号)

SAE 0W-20 API SP ILSAC GF-6A ACEA C5

Флагманское полностью синтетическое моторное масло линейки Lopal 1, разработанное под актуальные международные стандарты API SP и ILSAC GF-6A. Низковязкая формула SAE 0W-20 и фирменная технология присадок HyperZING обеспечивают уверенный пуск двигателя при низких температурах, надёжную защиту деталей и экономию топлива.

Преимущества

API SP · ILSAC GF-6A

Актуальные классы для современных бензиновых двигателей, включая защиту от преждевременного воспламенения на низких оборотах (LSPI).

SAE 0W-20

Низкая вязкость: лёгкий холодный пуск, быстрый прогрев и снижение расхода топлива.

Технология HyperZING

Фирменный пакет присадок Lopal (суперцинк) для защиты от износа и сохранения характеристик в течение интервала замены.

ACEA C5

Класс C5 совместим с современными системами нейтрализации отработавших газов.
