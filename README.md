# Lopal Kazakhstan — витринный сайт (скелет)

Статический скелет официального витринного сайта lopal.kz, разработанный по ТЗ на основе
корпоративного сайта lopal.cn. Разделы созданы **без наполнения контентом** — только структура,
навигация и демонстрация архитектуры страниц.

**Продуктовая линейка сайта — только автомобильные масла и технические жидкости**
(моторные масла, трансмиссионные масла, антифризы, тормозные жидкости). Промышленные масла,
AdBlue и автохимия в каталог не включены — по требованию заказчика.

## Структура

```
lopal-kz-site/
├── index.html            Главная (hero, о бренде, продукция, технологии,
│                         сертификаты, новости, CTA «Партнёрам»)
├── about.html            О бренде              (заглушка + план раздела)
├── products.html         Продукция             (каркас каталога + фильтр по категории)
├── product-sonic-9688.html  Полная карточка продукта-примера
│                         (Lopal 1 SONIC 9688 0W-20, API SP · GF-6A · ACEA C5)
├── technologies.html     Технологии            (карточки-заглушки + план раздела)
├── certificates.html     Сертификаты           (бейджи API/ACEA/OEM + план)
├── media.html            Медиацентр            (карточки-заглушки + план)
├── partners.html         Партнёрам / где купить (заглушка + B2B-форма)
├── contacts.html         Контакты              (карточки контактов + форма)
├── css/styles.css        Дизайн-система
├── js/main.js            Меню, фильтр каталога, тосты, демо-формы
└── README.md
```

## Как посмотреть

Вариант 1 — открыть `index.html` двойным щелчком (всё работает и с file://).

Вариант 2 — локальный сервер:

```bash
cd lopal-kz-site
python -m http.server 8080
# или: npx serve .
```

Затем открыть http://localhost:8080

## Что уже реализовано

- Структура разделов по ТЗ (п. 4): главная, о бренде, продукция, технологии,
  сертификаты, медиацентр, партнёрам, контакты.

## Что дальше (по этапам ТЗ, раздел 10)

1. **Стек**: выбрать фреймворк/CMS (Next.js/Nuxt + headless CMS или 1С-Битрикс) — статический
   прототип переносится в выбранную платформу.
2. **i18n**: структура URL `/ru/…`, `/kz/…`, `/en/…`; сейчас сайт русский, KZ/EN — заглушки.
3. **Контент**: перенос материалов с lopal.cn (каталог автомобильных масел, технологии,
   сертификаты, медиатека), перевод RU/KZ, согласование терминологии.
4. **Брендинг**: заменить предварительные цвета (CSS-переменные в `:root` в `css/styles.css`)
   на утверждённые бренд-значения. Официальный белый логотип уже подключён
   (`assets/logo-wht.png`) — в шапке и подвале на тёмно-зелёном фоне.
5. **Бэкенд-функции**: отправка форм с антиспамом, поиск по сайту, аналитика (GA4/Метрика),
   sitemap.xml, robots.txt, SSL.
6. **Сервисы по согласованию**: подбор масла (选油助手), проверка подлинности (防伪查询).
