# LOPAL Казахстан v2 — Официальный сайт ТОО «Topmaq oil»

Официальный витринный сайт бренда смазочных материалов **LOPAL (Jiangsu Lopal Tech Co., Ltd.)** в Республике Казахстан.
Генеральный дистрибьютор и официальный представитель — **ТОО «Topmaq oil» (TOPMAQ OIL)**, г. Алматы.

## 🚀 Основные возможности проекта v2

- **Главная витрина**:
  - Высококачественная адаптивная презентация бренда LOPAL и ТОО «Topmaq oil».
  - Премиальная светлая тема оформления.
  - Герой-блок с утренней панорамой гор Заилийского Алатау и фирменной композицией брендов.
- **Интерактивный каталог продукции**:
  - 14 отдельных детальных страниц (`product-*.html`) с характеристиками, допусками OEM, спецификациями и фасовками.
  - Легковые моторные масла (линейки 1 Advance, 1 Master, 1 Ultra с допусками API SQ, SP, ACEA).
  - Смазочные материалы для коммерческого транспорта и дизелей (Extra K10, Sonic 9688 CK-4).
  - Трансмиссионные жидкости (ATF 9800, CVTF 300S, DCTF 72X, DuraGear G500).
  - Охлаждающие и тормозные жидкости (Coolant C05, Coolant C08, DOT 4, DOT 5.1).
- **Интеллектуальный онлайн-подбор масла (`selector.html`)**:
  - Полноэкранный каталог подбора по марке, модели, двигателю и трансмиссии.
  - Автоматическое подавление всплывающих окон.
  - Интеграция с картой дилеров при клике на рекомендованное масло.
- **Интерактивная карта дилеров («Где купить»)**:
  - Модальное окно и отдельная страница `service-points.html` на базе Leaflet + OpenStreetMap.
  - 9 официальных сервисных центров и пунктов замены масла в Алматы с прямыми ссылками на маршруты в 2GIS.
- **SEO и метаданные**:
  - Полная семантика Schema.org (`AutoPartsStore`, `Product`).
  - OpenGraph, Twitter Card, валидные `robots.txt` и `sitemap.xml`.
  - 100% валидные ссылки, оптимизированные webp/svg/jpg изображения.

## 📁 Структура проекта

```text
├── index.html                 # Главная страница
├── products.html              # Каталог продукции
├── product-*.html             # 14 детальных карточек масел и техжидкостей
├── selector.html              # Интеллектуальный подбор масла (full-screen)
├── service-points.html        # Карта пунктов замены масла (ПЗМ) и дилеров
├── about.html                 # О бренде Lopal Tech
├── technologies.html          # Технологии и R&D
├── certificates.html          # Допуски OEM и сертификаты качества
├── contacts.html              # Контакты и реквизиты ТОО «Topmaq oil»
├── partners.html              # Для оптовиков и автопарков
├── css/
│   └── styles.css             # Стили оформления
├── js/
│   └── main.js                # Интерактивность и Leaflet-карта
├── assets/                    # Логотипы, сертификаты, фото канистр
├── functions/                 # Cloudflare Pages Functions (proxy /intell/)
├── robots.txt                 # Директивы для поисковых систем
└── sitemap.xml                # Карта сайта
```

## 💻 Локальный запуск

```bash
# Статический сервер
npx serve .
# или
python -m http.server 8080
```
