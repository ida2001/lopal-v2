Моторные масла · Дизельные · Lopal Extra (龙蟠赠程)

SAE 10W-40 API CK-4 дизель

Дизельное моторное масло линейки Lopal Extra (龙蟠赠程) класса API CK-4 — актуальной категории для современных дизелей с турбонаддувом и системами нейтрализации (DPF/SCR/EGR). Формула рассчитана на магистральные и строительные режимы коммерческого транспорта: стойкость к окислению, защита от износа и отложений.

API CK-4

Актуальный класс для дизелей: совместимость с DPF/SCR/EGR и стойкость к окислению.

Универсальная вязкость для смешанного коммерческого парка.
